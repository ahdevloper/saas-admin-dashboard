# SaaS Admin Dashboard

واجهة لوحة تحكم SaaS عربية (RTL) بهوية بصرية بيضاء مع الأخضر #2dba20 والأزرق #5555ff.

**Owner:** Ahmed Yassin — [@ahdevloper](https://github.com/ahdevloper)

## معاينة المشروع

واجهة ويب ثابتة تعمل مباشرة في المتصفح. لا تحتاج إلى تثبيت حزم أو تشغيل خادم محلي.

## المزايا الحالية

- لوحة رئيسية تتضمن مؤشرات الإيرادات والمستخدمين والاشتراكات والتحويل.
- رسوم بيانية توضيحية لتوزيع الخطط والإيرادات.
- تنقل بين أقسام النظرة العامة والتحليلات والمستخدمين والاشتراكات والفواتير والمنتجات والإعدادات والدعم.
- جدول مستخدمين مع بحث وتحديد وتصفية.
- نافذة لإضافة مستخدم إلى بيانات العرض التجريبي.
- تصدير قائمة المستخدمين بصيغة CSV.
- تصميم متجاوب للشاشات الكبيرة واللوحية والهواتف.
- واجهة عربية RTL مع دعم لوحة المفاتيح وتقليل الحركة.

## التشغيل

1. نزّل المستودع أو استنسخه.
2. افتح index.html في متصفح حديث.

أوامر الاستنساخ:
- git clone https://github.com/ahdevloper/saas-admin-dashboard.git
- cd saas-admin-dashboard

يمكن تشغيله عبر إضافة Live Server في VS Code أو أي خادم ملفات ثابت.

## ملاحظة مهمة حول البيانات

هذا الإصدار واجهة Frontend تجريبية. الأرقام والمستخدمون المعروضون بيانات توضيحية داخل المتصفح، ولا يوجد حالياً Backend أو قاعدة بيانات أو تسجيل دخول حقيقي أو معالجة دفع. إجراءات الإضافة والحذف تعمل على بيانات الجلسة فقط، وتصدير CSV ينشئ ملفاً من البيانات الحالية.
